1

Context header, zero questions. The palette opens already knowing the active capture target and its scopes, read straight from the shared SQLite store. You see where the thought will land before you type it.

2

The exact TUI command palette. Type / and the same fuzzy-filtered slash commands appear, name-matches ranked above description matches — /par prefers /park over /back. One grammar across CLI, TUI and desktop.

3

Escape hatches, not workflows. ↵ runs and the window evaporates; Ctrl+↵ runs and raises the Workbench for when a quick thought turns into a context switch you actually want.

4

Plain text is a note. Always. No mode to remember: anything without a slash is captured to the active branch, timestamped, done. Median time from shortcut to back-in-editor: about two seconds.
